# Colours

*English: First Steps - Colours - Level 1*

> **For the volunteer:** Bring coloured pencils. Hold up each pencil and say its colour; the learner repeats. Then say a colour and the learner picks the pencil.

## 1. Colour the boxes
Colour each box with the colour your volunteer says.

| red | blue | yellow | green | orange | purple |
|---|---|---|---|---|---|
| | | | | | |

## 2. Colour the picture
Draw a sun, grass, the sky and a banana. Colour them.

- The sun is yellow.
- Grass is green.
- The sky is blue.
- A banana is yellow.

## 3. I spy
Your volunteer says: "I can see something red." Find it and point!
